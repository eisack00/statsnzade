statsnzade searches and extracts data from Stats NZ’s Aotearoa Data Explorer (ADE) SDMX API. It follows the same shape as packages like OECD and rsdmx: list datasets, inspect a dataset’s structure, then download data.

{r setup} library(statsnzade)

Authentication

Every request needs a Stats NZ subscription key. Set the SNZ_PRIMARY_KEY environment variable (e.g. in .Renviron) so it’s picked up automatically, or set it for the current session:

{r} ade_set_api_key("your-subscription-key")

Listing and searching datasets

```{r} datasets <- ade_datasets() head(datasets)

ade_search_datasets(“food price”)


The very first call to `ade_datasets()` (or any other `statsnzade`
function that needs metadata) builds a local cache by walking every
dataset's metadata -- this takes a little while. Every call after that,
including in future sessions, reads the cache instead:

```{r}
ade_cache_info()

Force a rebuild if you know Stats NZ has published or changed a dataset:

{r} ade_cache_refresh()

Inspecting a dataset’s structure

{r} str <- ade_data_structure("CPI_ALC_001") str$dimensions str$CPI_MEASURE

Downloading data

```{r} # Whole dataset cpi <- ade_dataset(“CPI_ALC_001”)

Filtered by dimension code, and by time period

cpi_index <- ade_dataset( “CPI_ALC_001”, filter = list(FREQ = “M”, CPI_MEASURE = “B”), start_time = “2015” )


## Exploring interactively

```{r}
ade_metadata("CPI_ALC_001")

By default this renders the dataset’s name, description, and dimensions as a page in the RStudio Viewer (or your browser outside RStudio). Pass list = TRUE to get the raw data back instead:

{r} ov <- ade_metadata("CPI_ALC_001", list = TRUE) ov$name ov$dimensions

A caveat inherited from the API

Allowed codes (what you get from ade_data_structure()) are defined one dimension at a time. They don’t tell you which combinations of codes across dimensions actually occur in the data. To check that, query ade_dataset() and inspect the series that come back, or request detail=serieskeysonly directly against the data endpoint.
